# Bilge embed snippet

Include `bilge.js` (or the backward-compatible `pulse.js` shim) from your Bilge instance origin, for example:

`https://your-bilge.example.com/js/bilge.js`

Bump `version` in `package.json` when you want mirror-repo tags to reflect a new JS release. The main Bilge application repository may split this directory to a standalone mirror for distribution.
