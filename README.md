# Lookout embed snippet

Include `lookout.js` (or the backward-compatible `pulse.js` shim) from your Lookout instance origin, for example:

`https://your-lookout.example.com/js/lookout.js`

Bump `version` in `package.json` when you want mirror-repo tags to reflect a new JS release. The main Lookout application repository may split this directory to a standalone mirror for distribution.
